# 🤝 Contributing to Canon Visual Director

First off, thank you for considering contributing to **Canon Visual Director**! It's contributions like yours that make this AI Agent skill framework better for everyone in the open-source community.

感谢你考虑为 **Canon Visual Director** 贡献力量！正是有了社区的参与，这个 AI 视觉 Agent 技能才能不断演进。

---

## 💡 Ways to Contribute / 贡献方式

We welcome all kinds of contributions:
我们欢迎各种形式的贡献：

1. **📷 New Canon Optics Configurations (新镜头与色彩设置)**
   - Add parameters for newly released Canon RF lenses or specialized color science profiles (e.g., Canon Log 3 simulation, Vintage Canon FD lenses).
   - 补充佳能最新 RF 镜头、经典老镜（如 Canon FD）或色彩科学设置。

2. **🧠 New Visual Triggers (新的传播触发器)**
   - Expand the 12-Trigger Model with new psychological or social virality triggers for cover design.
   - 为 12 大传播 Trigger 模型扩充新的视觉传播心理学切角。

3. **🖼️ Showcase Examples (提交优秀生成的封面范例)**
   - Share high-quality generated images along with their prompts to be featured in the `assets/` directory.
   - 提交你通过本 Skill 生成的极具视觉冲击力的高质量封面及对应 Prompt，展示在 `assets/` 案例库中。

4. **🐞 Bug Fixes & Refinements (问题修复与语法优化)**
   - Fix typos, optimize YAML frontmatter, or clarify prompt rules in `SKILL.md`.
   - 修复文档错别字、优化 `SKILL.md` 中的提炼逻辑或语法规则。

---

## 🛠️ How to Submit a Pull Request / 如何提交 PR

1. **Fork the Repository** (在 GitHub 上 Fork 本仓库).
2. **Create a Feature Branch** (`git checkout -b feature/amazing-trigger`).
3. **Commit your Changes** (`git commit -m 'feat: add FD 50mm f/1.2 vintage lens support'`).
4. **Push to the Branch** (`git push origin feature/amazing-trigger`).
5. **Open a Pull Request** (在 GitHub 上开一个 PR 并说明修改要点).

---

## 📝 Code of Conduct & Guidelines / 行为准则与规范

- Keep `SKILL.md` clear, concise, and structured.
- Avoid camera spec stacking without story/metaphor justification.
- Respect open-source license agreements (MIT).

Thank you for building the future of AI Visual Direction with us! 🚀
